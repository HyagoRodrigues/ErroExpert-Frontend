# 🧠 ErroExpert - Web Client

O **ErroExpert Web** é a interface moderna e interativa onde os usuários gerenciam seu estudo reverso. Ele permite submeter questões erradas, visualizar análises detalhadas da IA, acompanhar estatísticas de desempenho e gerenciar um caderno de erros pessoal (flashcards).

## ✨ Principais Funcionalidades
- **Formulário Dinâmico:** Suporte para questões de "Múltipla Escolha" e "Certo/Errado".
- **Visualização de Análise:** Exibição clara de causas do erro, fundamentação teórica e flashcards.
- **Dashboard de Desempenho:** Gráficos interativos mapeando fraquezas técnicas.

## 🚀 Tecnologias Utilizadas
- **Next.js (App Router)** & **React**
- **Tailwind CSS** & **Recharts**
- **Supabase JS** (Autenticação)
